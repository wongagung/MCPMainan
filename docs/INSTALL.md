# Install

1. Extract the package to a permanent folder such as `D:\\Roblox-Universal-MCP`.
2. Run the provided Windows installer from `installer/` as Administrator.
3. Restart MCP-capable AI clients.
4. Open Roblox Studio and enable the Universal MCP plugin.
5. Confirm the plugin reports `127.0.0.1:58888` and `Connected`.

The MCP transport is stdio; port 58888 is only the local Studio bridge.

Node.js 20+ is required.
