# Feature matrix

- Universal MCP stdio for MCP-capable AI hosts.
- Studio tree/search/selection/script/instance/property/Luau tools.
- Runtime diagnostics and captured Output.
- Project, performance, security and asset audits.
- Snapshots with dry-run restore and no silent deletion of unrelated objects.
- Programmatic Play/Run/Multiplayer tests via StudioTestService.
- Durable project memory and local task tracking.
- Git status/diff/commit/push helpers.
- Bounded `roblox_autopilot` orchestration.

Viewport screenshots are intentionally not claimed here; support should depend on the Studio/client APIs actually available.
